## Что описывает это руководство

Аварийный пул трафика NodeNanny по умолчанию автоматически обнаруживает некоторые резервные источники узлов из открытых каналов, но вы также можете вручную указать источник, которому доверяете сами, — например, репозиторий с GitHub-подпиской, которым вы пользуетесь давно, или ссылку на подписку, опубликованную в Telegram-канале. Источник узлов, добавленный вручную, по умолчанию помечается как «фиксированно доверенный» — ему не нужно, как автоматически обнаруженному источнику, постепенно проходить путь от trial (испытательный срок) до trusted (полностью доверенный), прежде чем использоваться с полным весом.

## Где находится конфигурация

Откройте `config/config.json` (не `config.example.json` — это только шаблон) и найдите массив `manualSources`. В нём уже есть один пример:

```json
{
  "id": "wangcai",
  "name": "WangCai",
  "url": "https://shz.al/~WangCai",
  "fixed": true
}
```

Что означают четыре поля:
- `id`: уникальный идентификатор этого источника узлов — просто придумайте короткое имя на английском/латиницей, лишь бы оно не совпадало с уже существующим
- `name`: имя, отображаемое в панели, можно на китайском
- `url`: адрес ссылки на подписку
- `fixed`: установите `true`, чтобы этот источник сразу получил обращение как «фиксированно доверенный», минуя процесс оценки доверия. Это поле также можно не указывать (по умолчанию источник проходит обычный процесс оценки доверия, так же как автоматически обнаруженный источник) — какой вариант выбрать, зависит от того, насколько сильно вы сами доверяете этому источнику.

## Шаги для добавления нового источника

1. Найдите ссылку на подписку, которую хотите добавить (raw-ссылку на какой-либо репозиторий GitHub, или адрес подписки, которым с вами поделились)
2. В массиве `manualSources`, следуя формату записи `wangcai`, добавьте новую запись, например:

```json
{
  "id": "my-source-1",
  "name": "Моя собственная резервная подписка",
  "url": "вставьте сюда ссылку на подписку",
  "fixed": true
}
```

Не забудьте поставить запятую после предыдущей записи — формат JSON чувствителен к запятым и скобкам, поэтому после редактирования стоит вставить весь файл в онлайн-валидатор JSON и проверить формат, чтобы отсутствующая запятая не сломала чтение всего файла конфигурации.

3. Сохраните файл
4. Перезапустите процесс PM2 `nodenanny-pool`, чтобы новая конфигурация вступила в силу:

```
pm2 restart nodenanny-pool
```

5. Проверьте в панели статус пула трафика, чтобы убедиться, что новый добавленный источник появился и успешно получает узлы

## О Telegram-каналах как источниках

Если вы хотите добавить Telegram-канал, на данный момент работает только форма, при которой «ссылка на подписку размещена прямо в тексте сообщения канала» (`message_text_link`). Форма, при которой «ссылка размещена в виде файлового вложения в канале», сейчас не работает (публичная страница предпросмотра Telegram не предоставляет реальный URL для скачивания файлового вложения, а даёт лишь ссылку-редирект, которую технически невозможно использовать для этой цели). Поэтому при добавлении Telegram-канала как источника сначала убедитесь, что этот канал делится подпиской именно в виде текстовой ссылки, а не файла.

## Стоит ли устанавливать `fixed: true`

`fixed: true` означает, что этот источник минует оценку доверия и сразу получает полный вес — подходит для источника, который вы уже давно проверили и которому действительно доверяете (например, репозиторий, который вы сами поддерживаете). Для источника, который вы только что обнаружили и в качестве которого пока не уверены, лучше не указывать поле `fixed`, позволив ему пройти тот же обычный процесс оценки в течение испытательного срока, что и автоматически обнаруженному источнику — так, даже если качество этого источника окажется нестабильным, он не займёт высокий вес с самого начала. О том, как именно работает механизм доверия, подробнее рассказано в статье [Как работает механизм доверия пула узлов](./pool-trust-mechanism).
